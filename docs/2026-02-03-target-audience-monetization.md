# UsageTracker: целевая аудитория и стратегия монетизации

Стратегический отчёт (роль: CFO). Февраль 2026.

---

## 1. Кратко о продукте

**UsageTracker** — нативное macOS menu bar приложение для отслеживания лимитов использования AI-сервисов (Claude, Cursor, Codex, ElevenLabs, Stability, Runway, OpenAI). Данные и ключи хранятся локально, без телеметрии. Есть плагинная архитектура для добавления провайдеров.

**УТП:** один экран по всем провайдерам, локальность, мульти-провайдер (не только Cursor).

---

## 2. Исследование целевой аудитории

### 2.1 Рынок AI-инструментов для разработчиков (2024–2025)

- **Охват:** 84% разработчиков используют или планируют использовать AI-инструменты (2025); ~51% проф. разработчиков — ежедневно (Stack Overflow 2025).
- **Платящие пользователи:** GitHub Copilot — 1.3M платящих подписчиков, 30% Q-o-Q рост; 50k+ организаций; 90% Fortune 100 используют Copilot.
- **Тренд:** переход на usage-based цены (Cursor с июня 2025: $20/мес кредит, затем списание по API). Рост неожиданных счетов (примеры: +700% к привычному $20) создал спрос на инструменты контроля лимитов.
- **Доверие:** только ~42% разработчиков доверяют точности AI-инструментов; 72% относятся к ним положительно (снижение с 77%). То есть запрос на «контроль и прозрачность» высокий.

**Вывод:** аудитория большая, привыкла платить за AI (Cursor $20–200/мес, Copilot и др.), после смены моделей тарификации остро чувствует потребность в отслеживании лимитов и расходов.

### 2.2 Сегменты целевой аудитории

| Сегмент | Описание | Размер / доступ | Готовность платить | Приоритет |
|--------|----------|------------------|--------------------|-----------|
| **Разработчики на 2+ AI-сервисах** | Cursor + Claude Code и/или Codex, иногда API (OpenAI и др.). Хотят видеть все лимиты в одном месте. | Средний, растущий | Высокая ($20–60/мес уже платят за AI) | **Основной** |

| **Креаторы / фрилансеры** | ElevenLabs, Stability, Runway, OpenAI API. Нужен контроль расходов по подпискам и лимитам. | Средний | Средняя | Вторичный |
| **Малые команды (Business)** | Cursor Teams, несколько аккаунтов. Нужна видимость без тяжёлых корпоративных решений. | Меньший | Высокая при решении боли | Вторичный |
| **Enterprise** | Централизованный контроль, compliance. | Нишевый | Высокая, но длинные циклы продаж | Долгосрочно |

**География:** в первую очередь англоязычный рынок (США, UK, Канада, Австралия) и Европа; разработчики и креаторы с доходом выше среднего.

**Платформа:** только macOS 14+ (соответствует текущему продукту).

### 2.3 Конкуренты и позиционирование

- **Editor Usage for Cursor** (App Store): menu bar, только Cursor, $3.99 разовая покупка. Есть подписки/биллинг Cursor, предупреждения, Business-аккаунты.
- **Cursor Usage (cursorusage.com):** то же направление — Cursor, детальная аналитика, App Store.
- **Open-source:** скрипты и утилиты (Python и др.) для мониторинга Cursor/Claude; бесплатно, но без единого UX и без мульти-провайдера.

**Отличие UsageTracker:** мульти-провайдер (Claude, Cursor, Codex, ElevenLabs, Stability, Runway, OpenAI), локальность, плагины, один интерфейс. Конкуренты фокусируются на Cursor; UsageTracker решает задачу «все мои AI-лимиты в одном месте».

## 3. Рекомендации: кому продавать и как

### 3.1 Кому продавать в первую очередь

1. **Индивидуальные разработчики и просьюмеры**, которые:
   - платят за Cursor Pro/Pro+ и/или используют Claude Code / Codex;
   - используют больше одного AI-сервиса (код + голос/картинки/API);
   - ценят приватность и локальное хранение ключей.
2. **Малые команды (2–10 человек)** с Cursor Teams, которым нужна простая видимость использования без внедрения корпоративных панелей.

Каналы охвата: Twitter/X, Reddit (r/cursor, r/ClaudeAI, r/macapps), Dev.to, Product Hunt, блоги и подкасты про AI-инструменты для разработчиков.

### 3.2 Модель монетизации: разовая покупка vs подписка

**Рекомендация: разовая покупка (one-time purchase) как основная модель.**

| Критерий | Разовая покупка | Подписка |
|----------|------------------|----------|
| **Отраслевая норма** | Для macOS menu bar утилит доминирует разовая покупка (Hookmark, iStat Menus, Dato, 1Setter, Mumu). Подписка чаще у сервисов с облаком и постоянными затратами. | Типична для SaaS с серверами, API, обновлениями контента. |
| **Затраты продукта** | Нет облачной инфраструктуры, данные локально — нет повторяющихся cost на пользователя. | Нет объективной необходимости в повторяющемся доходе для покрытия инфраструктуры. |
| **Восприятие аудитории** | Разработчики ожидают «купил и владеешь» для утилит; подписка на «маленький виджет» часто вызывает отторжение. | Может быть принята, если явная ценность: синхронизация, бэкапы, команды. |
| **Конкуренция** | Editor Usage — $3.99 разово; аналоги в нише — чаще разово или через Setapp. | Редко для точечных menu bar приложений. |
| **Жизненный цикл** | Обновления можно включить в цену на 12–24 мес или «lifetime» с опциональным paid major upgrade. | Удобна, если позже появятся облачные/командные функции. |

**Итог:** основная модель — **разовая покупка** (например, $9.99–19.99), с возможностью:
- включить обновления на 12 месяцев в базовую цену;
- или «lifetime» в стиле Dato/1Setter;
- при появлении облака/командных фич — ввести **опциональную** подписку (premium tier), не заменяя разовую покупку для базового сценария.

### 3.3 Ценообразование (ориентиры)

- **Нижняя граница:** не ниже $4.99 (ниже — обесценивание и сложно расти в рейтингах).
- **Разовая покупка:** $9.99–19.99 в зависимости от позиционирования:
  - $9.99 — «доступный трекер лимитов», конкуренция с Editor Usage по функционалу Cursor + мульти-провайдер.
  - $14.99–19.99 — «все AI-лимиты в одном месте + приватность + плагины».
- **Опциональная подписка (будущее):** $1.99–2.99/мес только при появлении облачных/командных фич (синхронизация, общие дашборды).

### 3.4 Каналы продаж

1. **Собственный сайт + Gumroad / Paddle / Lemon Squeezy** — полный контроль, 90%+ выручки после комиссий, обновления вне правил App Store.
2. **Mac App Store** — доверие, поиск по «Cursor usage», «AI limit tracker»; комиссия 30% (15% для Small Business). Имеет смысл для охвата и социального доказательства.
3. **Setapp** — позже, при соответствии критериям: дополнительный охват, доля от подписной выручки Setapp; не заменяет прямые продажи.

Практично: запуск через **сайт + один платёжный провайдер** (Gumroad/Paddle), затем при наличии ресурсов — дублирование в App Store.

## 4. Риски и смягчение

| Риск | Смягчение |
|-----|-----------|
| Провайдеры меняют API/логины — трекер ломается | Плагинная архитектура и чёткое описание «best effort»; быстрые патчи при смене API. |
| Низкая осведомлённость о продукте | Контент: «как не переплачивать за Cursor/Claude», интеграция в обсуждения тарифов и лимитов. |
| Решение встроят в Cursor/Claude | Фокус на мульти-провайдере и локальности; ценность — один инструмент для всех сервисов. |

## 5. Итоговые выводы

- **Целевая аудитория:** в первую очередь разработчики на macOS, использующие 2+ AI-сервиса (Cursor, Claude Code, Codex, при необходимости — API), и power users одного сервиса после перехода на usage-based тарифы.
- **Монетизация:** основная модель — **разовая покупка** ($9.99–19.99); подписка — только как опция при появлении облачных/командных возможностей.
- **Продвижение:** контент и сообщества вокруг контроля лимитов и расходов на AI; Product Hunt, Reddit, Twitter/X; упор на мульти-провайдер и приватность.
- **Дистрибуция:** старт с прямых продаж (сайт + Gumroad/Paddle); при возможности — Mac App Store и позже Setapp.

Документ можно использовать для питчей, постановки маркетинга и принятия решений по цене и каналам.
